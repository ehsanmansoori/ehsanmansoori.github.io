# احسان منصوری | راوی سینما

هاب مستقل و یکپارچه محتوای احسان منصوری روی GitHub Pages:
https://ehsanmansoori.github.io

## چه چیزی در سایت هست

- کتابخانه ۹۱ فیلمی با پوستر و اطلاعات کامل از TMDB: عنوان فارسی، سال، مدت، ژانر، کشور، کارگردان، بازیگران، خلاصه، امتیاز و شناسه IMDb
- دو دسته اصلی: «چی ببینیم» (۸۷ فیلم سری و پاپ‌کورن) و «چی نبینیم» (۴ فیلم اکران بلیت)
- جستجوی زنده روی نام فیلم، کارگردان و بازیگر، به‌همراه فیلتر ژانر، کشور، دهه و مرتب‌سازی
- ۲۴ قسمت از سری «فیلم‌هایی که قبل از مرگ باید دید» و ادامه‌هایش، هر فیلم با تایم‌کد دقیق خودش
- ۵ قسمت تأییدشده پاپ‌کورن با متادیتای خوانده‌شده از کپشن خود ریلز
- بررسی چهار فیلم اکران روز در برنامه بلیت، هر فیلم با تایم‌کد فصل خودش
- بنر و آواتار برداشته‌شده از کانال رسمی یوتیوب
- چیدمان RTL با فونت وزیرمتن، بدون اموجی تزئینی و بدون کاراکتر em-dash

## منبع اطلاعات فیلم‌ها

طبق قرارداد پروژه، تنها منبع اطلاعات فیلم TMDB است (`build/fetch_films.py`). برای بازسازی متادیتا:

```bash
python3 build/fetch_films.py   # مرحله اول: TMDB به build/films_meta.json
python3 build/build_site.py    # مرحله دوم: build/films_meta.json به index.html
```

برای عنوان‌هایی که جستجوی TMDB نتیجه مبهم می‌دهد، شناسه با `PIN` در همان اسکریپت قفل شده است تا هیچ‌وقت فیلم اشتباه (مثلاً Wonder به‌جای Wonder Woman) انتخاب نشود.

## ساخت مجدد سایت

صفحه استاتیک تولید می‌شود، پس بعد از هر تغییر داده:

```bash
python3 build/build_site.py
```

اسکریپت `build/build_site.py` از `build/episodes_raw.json` می‌خواند و این‌ها را می‌نویسد:
`index.html`، `robots.txt`، `sitemap.xml`، `404.html`، `manifest.json` و آیکون‌ها و تصویر OG.

## داده‌ها و اعتبارسنجی

| بخش | منبع | نحوه تأیید |
|---|---|---|
| فهرست قسمت‌ها | پلی‌لیست یوتیوب `PLHPi-Jd5RkUEDw2PoJelP0bTz1EqteVd3` | صفحه پلی‌لیست با ترتیب واقعی |
| نام فیلم و تایم‌کد | فصل‌بندی داخل توضیحات هر ویدیو | استخراج از `shortDescription` همان ویدیو |
| کاور قسمت‌ها | `i.ytimg.com/vi/<id>/hqdefault.jpg` | هر ۲۴ تصویر با کد ۲۰۰ |
| پاپ‌کورن | کپشن ۵ ریلز اینستاگرام | شماره قسمت، کارگردان، کشور، سال و امتیاز از متن خود کپشن |
| بلیت | ویدیوی `Cg-HyOxAajs` | چهار فصل `1:00`، `3:30`، `6:25`، `8:30` |
| بنر و آواتار | صفحه کانال یوتیوب | نسخه ۲۱۲۰×۳۵۱ و آواتار ۹۰۰×۹۰۰ |

هفت ویدیو (قسمت چهارم، نوزدهم تا بیست و دوم و دو ویدیوی ویژه) در توضیحات و پلیر خود فصل‌بندی ندارند، پس برای آن‌ها فهرست فیلم ساخته نشده و کارتشان فقط به خود ویدیو لینک است. هیچ نام فیلمی حدس زده نشده.

# Ehsan Mansoori - Cinema Narrator Website

Personal website for Ehsan Mansoori, featuring film reviews, program showcases, and social media integration.

## Project Structure

```
ehsanmansoori.github.io/
├── assets/
│   ├── css/
│   │   └── style.css          # Main stylesheet with RTL support
│   ├── js/
│   │   └── main.js            # JavaScript functionality
│   └── images/                # Image assets
├── index.html                 # Main HTML file
└── README.md                  # Project documentation
```

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile
- **RTL Layout**: Full right-to-left support for Persian content
- **Interactive Elements**: Movie filtering, smooth scrolling, animations
- **Social Media Integration**: Links to YouTube, Instagram, Twitter
- **Contact Form**: Functional contact form with validation
- **Program Showcase**: Detailed sections for each TV program

## Technologies Used

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **JavaScript**: Vanilla JavaScript for interactivity
- **Vazirmatn Font**: Persian typography support

## Browser Support

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the main branch.
